# Session Handoff

Use this file when a session is interrupted or needs to continue in a new session.

## Template

```markdown
## Session: [brief description]
- **Date**: YYYY-MM-DD
- **Feature**: feat-XXX
- **Status**: in-progress / blocked / review
- **What was completed**:
  - [x] Task 1
  - [ ] Task 2 (in progress)
- **What remains**:
  - [ ] Task 3
  - [ ] Task 4
- **Blockers**: [describe or "none"]
- **Key decisions**: [any decisions made that affect future work]
- **Files modified**: [list key files changed]
- **Next step**: [what to do first when resuming]
```
